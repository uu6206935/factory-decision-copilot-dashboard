# 1.7.0 Warm Teal Enterprise UI RC1

Visual redesign only. Business logic, approval workflows, DeepSeek integration, data lineage, adaptive modules, APIs and routing remain intact.

## Design language
- Deep teal navigation chrome (#123c35 / #1f716d)
- Warm ivory application background (#f6f2e8)
- White cards with soft green-tinted shadows
- 18–24px card radius and softer control radius
- Muted semantic status chips: green / amber / coral / blue
- Light lineage canvas with teal relationship edges
- Approval Center restyled as a clean review workbench
- Responsive desktop/tablet/mobile behavior retained
